# Frontend Learning Playground

This repository is a personal training ground for learning frontend development.

The recommended learning path is:

> HTML → CSS → JavaScript → React → Projects

Real projects live in `00-projects`. The numbered folders are lessons.

Start with the browser fundamentals before moving to React. React concepts such as components, JSX, events, state, and list rendering depend on a solid understanding of JavaScript and the web platform.

## Exercise Convention

Each exercise can be organized as an independent example. A typical exercise may contain:

```text
01-example/
├── index.html
├── style.css
├── main.js
└── README.md
```

React exercises should remain in their own project directories with their own `package.json`. Keep React build files separate from vanilla HTML, CSS, and JavaScript exercises.

## Learning Workflow

For each topic:

1. Read the relevant documentation.
2. Write a small example from memory.
3. Build a focused exercise.
4. Record questions and mistakes.
5. Refactor the exercise after finishing it.
6. Apply the topic in a larger project.
