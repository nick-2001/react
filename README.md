# Frontend Learning Playground

A personal training ground for frontend development.

> HTML → CSS → JavaScript → React → Projects

Real projects live in `00-projects`. The numbered folders are lessons. Start with the browser before React: components, JSX, events, and state all depend on JavaScript and the web platform.

## Directory

```text
react/
├── 00-projects/
├── 01-basic/
├── 02-html/
├── 03-css/
└── 04-javascript/
```

Later folders can follow the same pattern: `05-react/`, then larger work back in `00-projects/`.

## Exercises

Keep each exercise in its own directory:

```text
01-example/
├── index.html
├── style.css
├── main.js
└── README.md
```

Give React exercises their own directory and `package.json`. Keep build output out of the HTML, CSS, and JavaScript lessons.

For each topic: read the docs, write a small example from memory, record mistakes, then use it in a larger project.
