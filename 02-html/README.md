# HTML Playground

This directory is for learning HTML fundamentals.

## How to run

Open `index.html` directly in a browser. No dependencies or build tools are required for the basic HTML exercises.

For a better development experience, you can use the Live Server extension in VS Code and open this directory as a workspace.

## Suggested practice order

1. Document structure and metadata
2. Headings, paragraphs, and text content
3. Links and navigation
4. Images, audio, and video
5. Lists and tables
6. Forms and native validation
7. Semantic HTML and accessibility

Use the MDN [HTML documentation](https://developer.mozilla.org/en-US/docs/Web/HTML) as the primary reference.
